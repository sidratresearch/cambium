# Changelog

## [Unreleased](https://github.com/sidratresearch/cambium/tree/main)

### Changed

- Moved incomplete documentation into a hidden folder

### Added

- Add fallback system for site title
- Add protections for `static/css/custom.css` and `static/js/custom.js`

## [0.6.0] - 2026-08-20

### Changed

- Store inter-page links in LeafMetadata
- Refactor link update system for Markdown pages
- Rename theme "default" to "root"
- Split Jinja header and footer into left/right/center

### Added

- Create redirect pages when moving readme.html to index.html
- Add configuration option for location of generated reports
- Add PreviewCSV stage
- Add Maple and blank themes
- Add option for stages to request inclusion of single CSS/JS files
- Add empty `custom.js`
- Add global options for domain and subpath

### Removed

- Removed Sitemap's stage configuration
