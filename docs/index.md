# Cambium Documentation

![Cambium Logo {height=300 .main-logo}](assets/cambiummainlogohorizontal.svg)

Cambium is a static site builder that is focused on communication within and by scientific and technical teams. Cambium takes directories of Markdown files and turns them into a static site that can be hosted anywhere without any special server setup. Cambium makes your information accessible and presentable right out of the box with the least amount of hassle.

## Features

## Why Cambium

We built Cambium because we needed a way to help scientific and technical teams rapidly communicate information amongst the group with the least effort. We needed something that worked right out of the box, but also had the capability to grow with the team.

## Try it yourself

To install Cambium:

`pip install cambium`

In your directory of Markdown files run:

`cambium`

And your website will be in `\_build`
